# Kumar Ansh Mishra — Portfolio

Personal portfolio built on the supplied React, Vite, Tailwind CSS, and GSAP template. The original layout, motion effects, and responsive styling are retained.

## Run locally

```sh
npm install
npm run dev
```

To enable the contact form, copy `.env.example` to `.env` and set valid EmailJS service, template, and public key values. The contact form reports when this setup is missing.

## Personal links still needed

The supplied project files did not include GitHub repository URLs for the showcased work, a LinkedIn profile URL, an email address, or a resume file. The portfolio marks those items as unavailable instead of linking to guessed destinations. CGPA Hub links to its supplied live website.
